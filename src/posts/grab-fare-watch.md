Grab（東南アジアの配車アプリ）の料金が上がっているのかどうか、今はまだわかりません。2026年4月にフィリピンへ引っ越してから、じわじわ高くなっている気がしていました。ところが半年分の利用明細を並べてみると、同じ道のりでも日や時間で100ペソほど揺れていて、値上がりかどうかを言える材料にはなりませんでした。そこで料金の記録を取り始めました。これからは定期的に調べられます。

## 行きは599ペソ、帰りの見積もりは1,200ペソ超

先週末の10月31日、マニラ・オーシャンパーク（マニラ湾沿いの水族館）に行きました。

行きは朝8時58分にGrabのStandard（一般的な乗用車の配車）を呼んで、599ペソでした。帰りの15時18分ごろにアプリを開くと、見積もりは1,200ペソを超えていました。行きのほぼ2倍です。さすがに乗る気になれず、同じアプリからメータータクシーを選んで帰りました。払ったのは563ペソでした。

同じ区間で、時間が違うだけで2倍。こういうことが続くと「最近Grab高くない？」という気持ちがたまっていきます。

## 半年分の利用明細を並べてみた

気のせいかどうかを確かめるために、Grabアプリから出せる利用明細（Member Statement）を5月5日から11月4日までの半年分取り出しました。フードやマートの注文を除いた配車の記録から、同じ道のりを何度か使ったものを拾ったのが次の表です（どれも自宅との往復です）。

| 行き先 | 日時 | 種類 | 料金 |
|---|---|---|---|
| 近所の病院へ | 5/22 14:33 | Standard | ₱227 |
| 同上 | 6/20 11:31 | Standard | ₱224 |
| 同上 | 10/3 11:36 | Standard | ₱227 |
| SSS（社会保障機構）の支店へ | 6/5 14:58 | Taxi | ₱213.50 |
| 同上 | 6/6 7:59 | Taxi | ₱193 |
| 同上 | 9/21 8:38 | Standard | ₱170 |
| ショッピングセンターから自宅へ | 5/6 12:08 | Standard | ₱479 |
| 同上 | 5/19 11:13 | Standard | ₱564.44 |
| 同上 | 9/23 10:44 | Standard | ₱503 |
| 近くの住宅地から自宅へ | 6/14 19:06 | Standard | ₱330 |
| 同上 | 9/20 19:57 | Standard | ₱236 |
| 同上 | 10/16 18:31 | 6人乗り | ₱348 |

病院へは5月も10月も227ペソで、まったく変わっていません。SSSへは9月がいちばん安く、ショッピングセンターからの帰りは5月19日がいちばん高い。近くの住宅地からの帰りは、同じ夜の時間帯でも236ペソから330ペソまで、100ペソ近い差があります。

## 1時間で105ペソ違った日

行きと帰りを両方記録できた道のりもあります。

| 道のり | 行き | 帰り |
|---|---|---|
| Festival Supermall（アラバンのショッピングモール）5/25 | 17:10 ₱230 | 20:57 ₱329 |
| 同上 7/18 | 11:22 ₱250 | 17:19 ₱312 |
| 美容院 5/12 | 12:28 ₱290 | 16:40 ₱247 |
| 日本大使館 9/24 | 13:43 ₱710 | 14:43 ₱815 |

9月24日の日本大使館は、行きと帰りの間がたった1時間で、105ペソ（約15%）高くなりました。11月3日にも大使館へ行っていて、このときは朝8時39分にタクシーで533ペソでした。Festival Supermallは2回とも、夕方以降の帰りのほうが高くなっています。同じ美容院へは、8月9日の朝9時38分に行ったときは194ペソでした。5月の290ペソより100ペソ近く安いです。

私の記録では、月による差よりも、その日その時間の揺れのほうがずっと大きいのです。しかも同じ道のりは多くて3〜4回しかありません。これでは「上がった」とも「上がっていない」とも言えません。

## スマホに毎時間、見積もりを取らせる

領収書は、乗ったときの料金しか残りません。そこで、乗らなくても料金を記録する仕組みを作りました。

自宅に置いたAndroidのスマホが、11月1日から24時間、1時間ごとに自動でGrabを開きます。決まった道のり（Old Zapote Public Marketから、Festival Supermall Alabangまで）の見積もりを出し、予約はせずに、料金と地図の画面を保存します。乗車地点は11月2日まではZapote Bridgeでしたが、ほかの配車アプリでも同じ場所を指定できるように変えました。今はGreen GSM（電気自動車のタクシー）とMove It（バイクタクシー）の見積もりも一緒に記録しています。

まだ数日分ですが、乗車地点を変えた11月2日12時20分から11月4日15時までの52回分で、Standardの見積もりは次のようになりました。

| 時間帯 | Standardの見積もり |
|---|---|
| 深夜0〜4時 | ₱295〜₱338 |
| 朝6〜9時 | ₱603〜₱717 |
| 昼11〜14時 | ₱325〜₱472 |
| 夜22〜23時 | ₱306〜₱317 |

いちばん安かったのは11月4日の2時の295ペソ、いちばん高かったのは同じ日の8時の717ペソでした。同じ日の同じ道のりで2.4倍です。朝の通勤時間の高さがはっきり出ていますが、まだ数日分なので、これは結論ではありません。

## 答えは、これから毎時間たまっていく

「Grab、上がってない？」という私の感覚は、半年分の領収書ではまだ確かめられませんでした。でも、水族館の帰りに2倍の見積もりを見て首をかしげたあの日から、スマホが毎時間、文句も言わずに見積もりを取り続けています。

数か月分たまったら、定期的に調べて、またここで報告します。そのころには、気のせいだったのかどうかがわかるはずです。
